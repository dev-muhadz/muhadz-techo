# Muhadz Techo Portfolio

Premium editorial-style portfolio and template catalog for **Muhadz Techo**.

## Stack
- Semantic HTML5
- Modern CSS3
- Vanilla JavaScript
- Zero external frameworks

## Structure
```text
/
├── index.html
├── css/main.css
├── js/main.js
├── assets/
├── robots.txt
├── sitemap.xml
└── README.md
```

## Add a project
Add an object to `PROJECTS` in `js/main.js` with a name, category, filter, live URL, visual class and label. Add a matching visual class in `css/main.css` if you want a custom preview treatment.

## Theme
Change `--ink`, `--paper`, `--paper-2`, `--acid`, `--muted`, `--shell` and `--radius-lg` at the top of `css/main.css`.

## SEO launch checklist
1. Update the canonical URL if a custom domain is connected.
2. Add a real Open Graph image before public launch.
3. Replace the inline favicon with a proper icon set if desired.
4. Keep titles and descriptions specific.
5. Add descriptive `alt` text when real project screenshots are introduced.
6. Keep `sitemap.xml` synchronized with the live URL.

## Positioning
The site is intentionally presented as a **digital studio and commercial template catalog**, rather than a traditional student portfolio. It can grow to include UI kits, open-source products, client work and future commercial templates.
